# Распределение ролей и ответственности

## Состав команды
1. Панченко Артём – Руководитель разработки
2. Екатерина Папазян – Программист
3. Трофим Орлов – Специалист по данным
4. Алишер Наврузбеков – Архитектор ПО
5. Илья Подъяпольский – Специалист по тестированию

## Обоснование выбора ролей
- **Руководитель**: опыт организации работы в проектной деятельности.
- **Программист**: наличие базовых знаний программирования и высокая заинтересованность.
- **Специалист по данным**: опыт работы с данными и интерес к игровой индустрии.
- **Архитектор ПО**: базовые навыки разработки и желание получить опыт проектирования.
- **Тестировщик**: опыт поиска недочётов и сильная мотивация к реализации проекта.

## Профессиональные стандарты и трудовые функции

### Руководитель разработки (Панченко Артём)
**Стандарт:** 06.017 «Руководитель разработки ПО»
**Функции:** Руководство процессами разработки; организация процессов; управление ресурсами.

### Программист (Екатерина Папазян)
**Стандарт:** 06.001 «Программист»
**Функции:** Разработка и отладка кода; проверка работоспособности; интеграция модулей; разработка требований.

### Специалист по данным (Трофим Орлов)
**Стандарт:** 06.042 «Специалист по большим данным»
**Функции:** Анализ больших данных; управление инфраструктурой анализа; разработка продуктов на основе данных.

### Архитектор ПО (Алишер Наврузбеков)
**Стандарт:** 06.005 «Архитектор ПО»
**Функции:** Управление архитектурой изолированных и интегрированных систем; управление единой информационной средой.

### Специалист по тестированию (Илья Подъяпольский)
**Стандарт:** 06.004 «Специалист по тестированию в области ИТ»
**Функции:** Подготовка тестовых данных; разработка тестовых случаев; анализ качества покрытия; управление процессом тестирования.
