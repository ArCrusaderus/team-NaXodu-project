# Договор команды (Team Contract)

## Способ коммуникации
Мы используем Telegram для оперативной связи и Discord для созвонов.

## Порядок обсуждения задач
- Задачи обсуждаем в общем чате.
- Важные решения принимаем голосованием большинства.

## Соблюдение сроков
- Дедлайны фиксируем заранее.
- Если не успеваем — предупреждаем команду минимум за 24 часа.
