# Правила взаимодействия команды

## Способ коммуникации
Для оперативной связи используется общий рабочий чат в Telegram. Мессенджер удобен для организации совещаний в формате видеоконференций (ВКС).

## Правила взаимодействия
1. Участники соблюдают этику общения и учитывают мнение друг друга.
2. Все основные вопросы обсуждаются в группе Telegram или на личных встречах.
3. Каждая задача закрепляется за конкретным участником и имеет назначенный срок выполнения.
4. Каждый участник отвечает за выполнение своих задач.
5. Важные решения принимаются после обсуждения со всей командой.
6. При возникновении проблем участник заранее сообщает об этом команде.
7. Перед закрытием задачи проводится совместная проверка результатов.
