# Матрица RACI: Работа с репозиторием проекта

## Легенда
-   **R (Responsible)** — исполнитель задачи.
-   **A (Accountable)** — ответственный за результат (утверждает работу).
-   **C (Consulted)** — консультируемый участник (предоставляет информацию до выполнения).
-   **I (Informed)** — информируемый участник (уведомляется после выполнения).

| Задача | Руководитель разработки (Панченко А.) | Программист (Папазян Е.) | Архитектор ПО (Наврузбеков А.) | Специалист по данным (Орлов Т.) | Специалист по тестированию (Подъяпольский И.) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Создание и настройка репозитория | **A** | I | **R** | I | I |
| Поддержание структуры папок и файлов | **A** | **R** | **R** | **R** | **R** |
| Написание отчётов по практическим работам | **A** | **R** | **R** | **R** | **R** |
| Внесение коммитов с осмысленными сообщениями | **A** | **R** | **R** | **R** | **R** |
| Проверка Pull Request (Code Review) | **A** | C | **R** | I | I |
| Слияние веток (Merge) | **A/R** | I | I | I | I |
| Резервное копирование и актуальность репозитория | **A** | **R** | **R** | **R** | **R** |
