# Матрица RACI: Подготовительный этап проекта

## Легенда
-   **R (Responsible)** — исполнитель задачи.
-   **A (Accountable)** — ответственный за результат.
-   **C (Consulted)** — консультируемый участник.
-   **I (Informed)** — информируемый участник.
