# Матрица RACI: Работа с репозиторием проекта

## Легенда
-   **R (Responsible)** — исполнитель задачи.
-   **A (Accountable)** — ответственный за результат.
-   **C (Consulted)** — консультируемый участник.
-   **I (Informed)** — информируемый участник.

| Задача | Руководитель разработки (Панченко А.) | Архитектор ПО (Наврузбеков А.) | Программист (Папазян Е.) | Специалист по данным (Орлов Т.) | Специалист по тестированию (Подъяпольский И.) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Создание и настройка репозитория | **R/A** | **R** | I | I | I |
| Поддержание структуры папок и файлов | **R/A** | **R** | **R** | **R** | **R** |
| Написание отчётов по практическим работам | **R/A** | **R** | **R** | **R** | **R** |
| Внесение коммитов с осмысленными сообщениями | **R/A** | **R** | **R** | **R** | **R** |
| Проверка Pull Request | **R/A** | I | I | I | I |
| Слияние веток (merge) | **R/A** | I | I | I | I |
| Резервное копирование и поддержание актуальности | **R/A** | **R** | **R** | **R** | **R** |
