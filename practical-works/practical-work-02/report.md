### 3. Структура репозитория
Репозиторий организован строго по схеме из методических указаний к СР2:

*(Вставьте сюда скриншот дерева папок с сайта GitHub или из GitHub Desktop)*

**Описание структуры:**
-   **README.md** — общее описание проекта, состав команды, ссылки на документацию.
-   **docs/** — правила взаимодействия (`team-contract.md`), распределение ролей (`roles-and-responsibilities.md`), матрица RACI (`raci-matrix.md`).
-   **practical-works/** — изолированные папки для каждой из 8 практических работ с подпапками `assets/` и `src/`.

-   **.gitignore** — правила исключения временных и служебных файлов.

### 4. Распределение обязанностей по работе с репозиторием
Обязанности закреплены согласно матрице RACI (СР1) и пункту 4 методички СР2:

| Обязанность | Исполнитель (R) | Ответственный (A) |
| :--- | :--- | :--- |
| Создание и настройка репозитория | Архитектор ПО | Руководитель разработки |
| Поддержание структуры папок и файлов | Все участники (за свои разделы) | Руководитель разработки |
| Написание отчётов по практическим работам | Все участники (согласно ролям) | Руководитель разработки |
| Внесение коммитов с осмысленными сообщениями | Каждый участник за свои изменения | Руководитель разработки |
| Проверка Pull Request | Архитектор ПО / Руководитель | Руководитель разработки |
| Слияние веток (merge) | Руководитель разработки | Руководитель разработки |
| Резервное копирование и актуальность | Все участники | Руководитель разработки |
