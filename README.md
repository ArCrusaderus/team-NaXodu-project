# На Ходу

## О проекте
Данный проект представляет собой разработку прототипа веб-сервиса для подбора персональных рекомендаций компьютерных игр. Система анализирует предпочтения пользователей, жанры и поведение игроков, чтобы предлагать релевантные игры. Проект выполняется в рамках дисциплины «Введение в профессиональную деятельность» по направлению 09.03.04.

**Цель проекта:** формирование навыков командной разработки ПО, распределения ролей и создания работающего прототипа без углублённого программирования.

## Структура репозитория
Репозиторий организован согласно методическим указаниям к самостоятельным работам:

- **docs/** — документация команды (договор, роли, матрица RACI)
- **practical-works/** — отчёты по практическим работам (СР1–СР8)
- **scripts/** — вспомогательные скрипты
- **.gitignore** — правила исключения файлов из контроля версий
